# UX Blueprint

## Core screens
- Control coverage dashboard
- Evidence workspace for a single control
- Gap inbox with targeted follow-up requests
- Approval queue for exceptions and overrides
- Frozen audit pack viewer with provenance timeline

## UX feel
- Calm, precise, and evidence-first rather than chat-first.
- The product should feel closer to a reviewable case file than an agent toy.
- Every AI-generated assertion should have visible source links and confidence cues.

## Information architecture
- Portfolio view by framework, entity, and period
- Drill-down from control to evidence set to artifact to decision log
- Separate surfaces for working evidence versus frozen evidence packs
- Explicit status markers for draft, review, approved, and exported

## What makes the product feel premium and agent-native
- Side-by-side evidence and narrative review instead of forcing users to bounce between tabs.
- A visible evidence graph that shows why the system thinks an artifact proves a control.
- One-click provenance expansion for every claim.
- Exception handling that feels like adjudication, not ticket triage.
